# User PT Batok Kelapa (Web Karyawan & Camera Scanner)

Aplikasi operasional karyawan PT Produksi Batok Kelapa untuk login praktis dan scan foto kertas catatan kerja harian menggunakan kamera perangkat.

## ✨ Fitur Utama
- **Login Karyawan**: Menggunakan NIK & PIN 6-digit.
- **Beranda & Profil Tim**: Menampilkan profil divisi kerja dan status setoran catatan kerja hari ini.
- **Camera Scanner Otomatis**: Akses kamera belakang (`facingMode: environment`), overlay bingkai scan, preview, pemilihan shift kerja, dan upload langsung ke Cloud Storage Supabase.

## 🛠️ Tech Stack
- Next.js 15 (App Router, TypeScript)
- Tailwind CSS
- Supabase JS Client & Storage

## 🚀 Menjalankan Project
```bash
npm install
npm run dev
```
Buka browser di `http://localhost:3002`.
